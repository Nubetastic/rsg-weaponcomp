Example workflow

Start with a Bolt Action style

Customize the Bolt Action, save the style, and load it while working on the Mauser or Carcano. The style applies matching categories and safely skips anything the new gun cannot use.

Usually transfers

Shared appearance

  • Metal materials and matching colors
  • Engraving patterns and engraving metals
  • Tints
  • Wrap choices when both guns support wraps
May be skipped

Weapon-specific parts

  • Barrel, grip, stock, clip, and sight variants
  • Scopes on guns without a scope category
  • Role, collector, bounty, and legendary parts
  • Any option with no matching category and name
Make one style more compatible

Add categories from another gun

A style can grow without losing its existing setup. This works best when the original weapon does not offer a category that another weapon has.

  1. LoadOpen the second gun and load the saved style.
  2. CustomizeChoose the extra parts that only this gun offers.
  3. Add MissingAdd only categories not already stored in the style.
Scope example Start with a weapon that has no scope category. On a scoped weapon, load the style, select a scope, then use Add Missing. If the style already stores Scope as None, use Update to replace that choice.
CompatibleWill apply to this gun.
UnsupportedThis gun does not have that category.
InvalidThe category exists, but no matching option was found.

Skipped parts do not stop the compatible parts from applying.
